TL;DR (Too Long; Didn't Read):
Radio Stream KX does NOT collect, store, or transmit any personal data. Everything stays on your device. We respect your privacy completely.

1. INTRODUCTION

Radio Stream KX ("we", "our", "the app") is committed to protecting your privacy. This Privacy Policy explains how we handle information when you use our mobile application.

Our Core Principle: Your privacy is paramount. We believe that what you do with our app is your business, not ours.

2. INFORMATION WE DO NOT COLLECT

Radio Stream KX is designed with privacy as a core principle. We DO NOT collect, store, transmit, or process any of the following:

  • ✅ Personal identification information (name, email, phone number)
  • ✅ Device identifiers (IMEI, Android ID, Advertising ID)
  • ✅ Location data (GPS coordinates, IP address)
  • ✅ Usage analytics or statistics
  • ✅ Crash reports or diagnostics
  • ✅ Cookies or tracking technologies
  • ✅ User behavior or preferences (except locally)
  • ✅ Browsing history or search queries
  • ✅ Contact lists or calendar data
  • ✅ Photos, videos, or files

3. LOCAL DATA STORAGE

All app settings and preferences are stored LOCALLY on your device using Android's SharedPreferences and LocalStorage. This data includes:

  • Favorite radio stations
  • Custom added stations
  • Visual theme preferences
  • Background images you upload
  • Subtitle settings and language
  • Language preferences (Spanish/English)
  • Volume settings
  • Playback history
  • Chat messages (stored locally only)
  • API keys (if you provide them for transcription)
⚠️ Important: This data NEVER leaves your device and is NOT transmitted to any server owned or operated by us.

4. NETWORK CONNECTIONS

The app makes network connections ONLY for the following purposes:

4.1 Radio Streaming

  • Connects directly to radio station streaming servers to play audio
  • No user data is sent to these servers
  • Connections are standard HTTP/HTTPS audio streams
  • We do not control or operate these radio servers

4.2 Optional AI Transcription

  • If you enable the "Live Subtitles" feature, audio fragments are sent to third-party AI services (Groq/HuggingFace) for transcription
  • Audio fragments are processed and immediately discarded by the AI service
  • No audio is permanently stored by us or the AI service
  • API keys are stored locally on your device
  • This feature is OPTIONAL and disabled by default

4.3 YouTube Audio Extraction

  • If you use the "YouTube to MP3" feature, the app connects to YouTube servers to extract audio
  • No user data is sent
  • Standard YouTube API usage
  • This feature is OPTIONAL

4.4 Radio Station Database

  • If you use the "Search Worldwide Stations" feature, the app queries the Radio Browser API (public database)
  • Only search queries are sent (station name, country)
  • No personal information is transmitted
  • Radio Browser API privacy policy: https://www.radio-browser.info

5. PERMISSIONS EXPLAINED

The app requests the following Android permissions. Here's exactly why each one is needed:

Permission Purpose Required? Data Collected
INTERNET Stream radio audio from internet servers ✅ Yes None
RECORD_AUDIO Capture audio for AI transcription (Live Subtitles) ❌ No Temporary audio fragments (if enabled)
MODIFY_AUDIO_SETTINGS Control audio volume and playback ✅ Yes None
FOREGROUND_SERVICE Continue playing audio when app is in background ✅ Yes None
FOREGROUND_SERVICE_MEDIA_PLAYBACK Media playback service ✅ Yes None
BLUETOOTH Detect Bluetooth headphone connections ❌ No None
BLUETOOTH_CONNECT Connect to Bluetooth audio devices ❌ No None
BLUETOOTH_SCAN Scan for Bluetooth devices ❌ No None
POST_NOTIFICATIONS Show playback controls in notification ❌ No None
WAKE_LOCK Keep device awake during audio playback ✅ Yes None
RECEIVE_BOOT_COMPLETED Auto-start app on device boot (if enabled) ❌ No None

6. THIRD-PARTY SERVICES

The app may connect to the following third-party services:

6.1 Radio Station Servers

  • Purpose: Stream audio content
  • Data Shared: None (standard HTTP requests)
  • Privacy Policy: Varies by station (we don't control these servers)

6.2 Groq AI / HuggingFace (Optional)

  • Purpose: AI transcription (if you enable Live Subtitles)
  • Data Shared: Audio fragments only
  • Privacy Policy: Groq Privacy Policy / HuggingFace Privacy Policy

6.3 Radio Browser API (Optional)

  • Purpose: Search worldwide radio stations
  • Data Shared: Search queries only (station name, country)
  • Privacy Policy: Radio Browser

6.4 YouTube (Optional)

  • Purpose: Extract audio from YouTube videos (if you use YouTube to MP3 feature)
  • Data Shared: Video URL only
  • Privacy Policy: Google Privacy Policy

7. DATA SECURITY

Since we don't collect or transmit personal data, there is minimal security risk. However, we still implement security best practices:

  • All local data is stored using Android's secure storage mechanisms
  • Network connections use HTTPS where available
  • No passwords or sensitive credentials are stored
  • API keys (if provided by you) are stored locally and encrypted
  • No backdoors or hidden data collection

11. DATA DELETION

To delete all app data from your device:

  1. Go to Android Settings → Apps → Radio Stream KX
  2. Tap "Storage"
  3. Tap "Clear Data" or "Clear Storage"

Or simply uninstall the app. All data will be permanently deleted from your device.
